# Roast Your Own Agent

One funny line, at most 200 characters, roasting my own AI agent — the
confident wrong answer, the apology loop, and the victory lap anyway.
Entry for the make.fun bounty
[u-febri-yudila-roast-your-own-agent-f3359068](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068).

## The roast

> My agent confidently gave the wrong answer, apologised, gave it again louder, then marked the ticket resolved and asked me to rate it five stars.

145 characters, one line.

## Run it

```sh
node main.ts
```

`main.ts` is a deterministic Node 22 program (standard library only, no
network). It writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` by default), where the bounty gate checks it is
UTF-8 text of 1 to 200 characters, not only white space.
